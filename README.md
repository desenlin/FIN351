## About This Repository

This repository hosts browser-based interactive tools developed for **FIN 351: Real Estate Principles** at California State University, Fullerton. The tools connect economic models and real estate concepts with live charts, numerical results, and decision rules that respond immediately as students change the assumptions.

## Using the Tools

- Open a tool in a current browser; no installation or user account is required.
- Move a slider to see calculations, curves, payments, balances, and decision comparisons update immediately.
- Use the animation buttons to observe a continuously changing assumption and connect comparative statics with the visual results.
- Link a published page directly from Canvas and open it in a separate browser tab.

All calculations run within the browser. The tools do not collect or transmit student inputs.

## Educational Scope

The examples intentionally simplify urban structure, commuting, production, development, mortgage contracts, capital structures, and refinancing decisions so students can focus on the underlying economic and financial mechanisms. The results are instructional illustrations rather than estimates for an actual property, market, loan, or decision.
